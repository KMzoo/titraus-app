# Titraus

Asennettava lääkepäiväkirja (PWA). Tämä repo sisältää vain julkaistut sovellustiedostot.

- Sovellus ei tee verkkopyyntöjä. Kaikki merkinnät pysyvät vain siinä laitteessa, johon se on asennettu.
- Asenna avaamalla Pages-osoite puhelimen selaimessa → *Asenna sovellus* (Android) tai
  *Jaa → Lisää Koti-valikkoon* (iOS). Sen jälkeen sovellus toimii ilman verkkoa.

Lähdekoodi ja dokumentaatio ovat erillisessä yksityisessä repossa.
